Driver help (Windows)

Serial tower on a Prolific USB-serial cable: if the COM port is named "PL2303TA DO NOT SUPPORT WINDOWS 11", Windows Update gave it the driver that refuses older chips. Install the older driver from github.com/BrandonVP/Prolific: Device Manager → the port → Update driver → Browse my computer → Let me pick → Have Disk → the folder extracted from PL2303_Prolific_v3.8.38.2.cab (black/newer cables) or, for grey/older cables, run PL2303_Prolific_v3.3.2.105.exe and pick the 2008 driver. Then block driver auto-update (Device Installation Settings → No).

LEGO USB tower: LEGO's driver is 32-bit only. Install the generic WinUSB driver with Zadig: Options → List All Devices → "LEGO USB Tower" (0694 0001) → target WinUSB → Replace Driver.

OpenRCX DIY tower: no driver needed; Teensy and ESP32 boards use Windows' built-in USB serial driver.

Full instructions: OpenRCX README, Drivers.
