# openmindstorms (Python)

Command-line tools and libraries for the LEGO Mindstorms bricks:

* `rcx` / `openrcx` - RCX through an IR tower (serial, DIY Teensy, or USB tower)
* `nxt` / `opennxt` - NXT over USB (WinUSB) or Bluetooth

```
pip install -e python
rcx --help
nxt --help
```

Full documentation: ../README.md
