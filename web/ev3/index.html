Connect to the brick

Switch the EV3 on, pick USB or Bluetooth, connect. Chrome or Edge is required. No driver is needed for USB.

Link

Connection help

USB: plug in, switch on, press Connect and pick "LEGO MINDSTORMS EV3" in the browser's picker. If the picker shows nothing, another program (the LEGO app, a previous tab) may be holding the brick.

Bluetooth: on the brick: Settings → Bluetooth → Bluetooth on, Visibility on. Windows: Settings → Bluetooth → Add device → the brick → confirm the passkey on the brick. Then use the COM port marked outgoing in Device Manager. The brick shows up under its brick name, not as "LEGO" or "EV3": the factory name is EV3, but a renamed brick appears under that name (for example STU). The Brick panel on the right shows the name once connected, and you can change it there.

macOS: nothing to install. USB works as above. Bluetooth: System Settings → Bluetooth → Connect to the brick (confirm the passkey on the brick), then Connect here and pick the port named after the brick. Safari does not work; use Chrome or Edge.

Linux: USB needs a udev rule so the browser may open the brick, for example KERNEL=="hidraw*", ATTRS{idVendor}=="0694", ATTRS{idProduct}=="0005", MODE="0666" in /etc/udev/rules.d/50-ev3.rules, then replug. Bluetooth: pair, then sudo rfcomm bind 0 <brick address> and pick /dev/rfcomm0.

Python instead of blocks? Pybricks runs natively on the EV3 (installed from the browser over USB, reversible). A brick running Pybricks no longer speaks the LEGO protocol, so it will not connect here until LEGO firmware is restored.

Python on the EV3 with Pybricks

          
Pybricks is a free MicroPython firmware with its own browser editor. It replaces the LEGO firmware on the brick (and can be put back) and gives you a modern Python API for motors and sensors.

          
    
            
  1. Switch the brick off. Hold the back and enter buttons while pressing enter, then release back when the brick shows its update screen (the "clicking" firmware-update mode). Connect over USB.
    2. 
            
  2. Open beta.pybricks.com (EV3 support is in the beta version), choose Install Pybricks firmware, and pick the EV3.
    3. 
            
  3. Write and run Python there. To return to LEGO firmware and this Workbench, use the same page's "Restore official LEGO firmware".
    4. 
          

          
OpenEV3's blocks and control panel need the LEGO firmware, so a brick is either on Pybricks or on LEGO firmware at any one time; switching takes a few minutes.
