Driver help (Windows)

USB: LEGO's driver is 32-bit only and conflicts with the browser. Install the generic WinUSB driver with Zadig: Options → List All Devices → "LEGO MINDSTORMS NXT" (0694 0002) → target WinUSB → Install/Replace Driver. To get NXT-G or BricxCC talking again later, uninstall the device in Device Manager and replug.

Bluetooth: on the brick: Bluetooth → On → Visible. In Windows: Settings → Bluetooth → Add device → NXT → PIN 1234. Windows then lists two COM ports for it under Bluetooth in Device Manager; use the one marked outgoing. No driver needed, but replies are slower than USB.

Full instructions: README, Drivers.
