OpenMindstorms

Free tools that bring the LEGO Mindstorms bricks back to life on today's computers. Everything runs in Chrome or Edge: write programs with blocks or text, compile, download, and drive the robot, with nothing to install.

OpenRCX 1998 · RCX

The original yellow brick. Programs travel over infrared through a LEGO serial tower, the LEGO USB tower, or a tower you build yourself from a Teensy (guide and sketch included).

  • Block editor in the spirit of RCX Code, plus NQC text
  • Compiler runs in the browser; firmware install and datalog too
  • Verified on a real RCX 2.0
Open OpenRCX

OpenNXT 2006 · NXT

The grey brick with USB and Bluetooth built in: encoder motors, ultrasonic and colour sensors, a pixel display and a file system.

  • Connect over USB or Bluetooth straight from the browser
  • Drive motors and read sensors live; manage files on the brick
  • NXC text and NXT-G style blocks, compiled on the server
Open OpenNXT

OpenEV3 2013 · EV3

The Linux-based brick with the big display: large and medium motors, gyro, colour, ultrasonic and infrared sensors, and a proper file system.

  • Connect over USB (no driver) or Bluetooth straight from the browser
  • EV3-G style blocks compiled to brick bytecode in the browser; run now or save to the brick
  • Drive motors, read sensors and manage files live; Python through Pybricks
Open OpenEV3
